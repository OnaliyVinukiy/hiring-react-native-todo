# tasked - React Native Todo App

A todo list app built with React Native following the Figma design "tasked".  
Features include tasks, subtasks, local persistence, editing, deleting, and animations.

---

## 🚀 Features

- View a list of TODO items
- Add new tasks and subtasks
- Edit tasks and subtasks
- Toggle completion (checked/unchecked)
- Delete tasks and subtasks
- Expand/collapse subtasks
- Swipe-to-delete animation
- Local persistence using AsyncStorage

---

## 💻 Prerequisites

- Node.js >= 18.x
- npm >= 9.x or yarn >= 1.x
- Expo CLI (`npm install -g expo-cli`)
- A device or emulator to run the app (iOS Simulator, Android Emulator, or Expo Go app)

---

## 🛠️ Setup & Running the App

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   ```
2. Navigate into the project folder
   ```bash
    cd tasked
   ```
3. Install dependencies:
   ```bash
    npm install
    #or
    yarn install
    ```
4. Start the app:
    ```bash
    npx expo start
    ```
